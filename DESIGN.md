# Abitura – дизайн-система «Азия / красный»

> Источник правды: `app/src/index.css` (Tailwind 4 `@theme` + CSS-переменные).
> Светлая «бумажная» тема – **по умолчанию** (`:root`); тёмная «чернила» включается атрибутом `[data-theme="dark"]` на `<html>`.
> Референс – zhuiqiu.io: глубокий красный на кремовой бумаге, Playfair Display в заголовках, иероглифы рядом с русским, печать как знак продукта. Наша интерпретация, не копия.

---

## Идея в трёх строках

1. **Бумага и чернила.** Страница – кремовая бумага, текст – чернила. Карточки белые, с едва заметной тенью.
2. **Красный – акцент, не заливка.** Заголовки, кнопки, печати, тонкие линии, кикеры. Красных полей на всю страницу не бывает; красная полоса допустима как отдельный блок (цитата, CTA-баннер) с кремовым или золотым текстом.
3. **Печать (印章) и иероглифы.** Проверенный факт отмечен красной квадратной печатью. Разделы подписаны иероглифом с русским значением рядом. Больше одного кикера на блок не ставим, иероглиф без перевода не оставляем.

## Типографика

| Роль | Шрифт | Начертания | Токен / класс |
|------|-------|-----------|---------------|
| Заголовки (h1–h3, CardTitle, DialogTitle) | **Playfair Display** | 700, 800 | `--font-display` → `font-display` (h1–h3 получают его из базовых стилей) |
| Текст, кнопки, метки | **Noto Sans** | 400, 600 | `--font-body` → `font-body`; `font-sans` – синоним |
| Иероглифы | системный CJK: Noto Sans SC → PingFang SC → Hiragino Sans GB → Microsoft YaHei | – | `--font-cjk` → `font-cjk`; элементы с `lang="zh-Hans"` получают его автоматически |

- Шрифты грузятся с fonts.googleapis.com (`app/index.html`): Playfair Display 700;800 + Noto Sans 400;600, кириллица подключается через unicode-range. Тяжёлый CJK-шрифт **не грузим**.
- Крупные заголовки часто **капителью с разрядкой**: утилита `caps` (`uppercase` + `letter-spacing: 0.14em`), например `font-display caps text-3xl font-extrabold text-accent-text`.
- Иероглифы вживлены в русский текст: «北京大学 «Бейда»», «追求完美 – стремитесь к идеалу». Оборачивать в `<span lang="zh-Hans">`.
- Кавычки «ёлочки», тире – en-dash (–), без эмодзи, без стрелок на кнопках.

### Контраст (WCAG, посчитано скриптом)

Светлая: fg/bg 15.3:1 · fg-muted/card 7.2:1 · fg-muted/bg 6.6:1 · accent-text/bg 8.3:1 · accent-fg/accent 8.3:1 · gold/accent 7.1:1 · gold/ink 13.1:1 · warning/card 5.2:1 · positive/card 5.4:1 · danger-fg/danger 5.9:1.
Тёмная: fg/bg 16.2:1 · fg/card 12.0:1 · fg-muted/card 6.3:1 · accent-text(золото)/card 10.7:1 · accent-fg/accent 5.9:1 · gold/accent 5.1:1 · danger-fg/danger 7.7:1 · warning/card 7.0:1.
`fg-faint` держит ≥ 3:1 на карточке в обеих темах (4.3:1 / 3.5:1) – только для декора и крупных подписей. Сплошная красная печать на графите – 2.1:1 по краю, поэтому в тёмной теме у неё тонкий светлый ободок (`index.css`).

## Правила красного

1. **Красный текст** → `text-accent-text` (в тёмной теме это золото – так задумано). Не `text-accent`.
2. **Красные заливки** → `bg-accent` + `text-accent-fg`, метки **semibold**. Кнопка `default`, активный сегмент, чекбокс/переключатель, печать.
3. **Тонкие линии** → `border-accent`, утилита `rule-accent` (1px верхняя линия), цитата – `border-l-2 border-accent`.
4. **Красные полосы** (цитата по-китайски с переводом, CTA-баннер): `bg-accent text-accent-fg`, акценты внутри – `text-gold`, кикер – `<HanziKicker tone="inverse">`. Не больше одной полосы на экран, чередовать с кремовыми.
5. **Тёмные полосы**: `bg-ink text-paper`, акценты – `text-gold`.
6. Свечений, градиентов и теней под кнопками нет. Единственная тень – у белой карточки на бумаге (задаётся глобально для `[data-slot="card"]`).
7. `danger` тоже красный: используйте его только с явной подписью («Удалить», «Ошибка») и никогда как декоративный акцент.

## Печать – `Seal` (`app/src/components/ui/seal.tsx`)

Главный визуальный знак продукта: квадрат с рамкой и внутренней линией, внутри один иероглиф.

```tsx
<Seal />                                        // 印, sm, solid, accent – «проверено»
<Seal glyph="手" size="md" />                    // введено вручную
<Seal glyph="档" variant="outline" tone="warning" />  // архивная копия
<Seal glyph="试" variant="outline" tone="muted" />    // демо
```

| Проп | Значения | По умолчанию |
|------|----------|--------------|
| `glyph` | любой иероглиф | `印` |
| `size` | `sm` (20px) · `md` (28px) | `sm` |
| `variant` | `solid` (заливка, кремовый знак) · `outline` (контур) | `solid` |
| `tone` | `accent` (красный) · `warning` (архив) · `muted` (демо, серый) | `accent` |

Печать декоративна и `aria-hidden`, если не передан `title` / `aria-label`: смысл всегда несёт подпись рядом. Четыре состояния бейджа провенанса (`ProvenanceBadge`) различимы по печати **и** по тексту: `auto` 印 solid, `manual` 手 solid, `wayback` 档 outline warning, `demo` 试 outline muted (+ вариант бейджа `secondary`).

## Кикеры

- **`Kicker`** (`ui/kicker.tsx`) – обычный верхний ярлык: Noto Sans 600, 12px, uppercase, разрядка 0.14em; `accent` красит его в `text-accent-text`. API прежнее (`as`, `accent`).
- **`HanziKicker`** (`ui/hanzi-kicker.tsx`) – иероглиф + русское значение, один компонент для всех разделов:

```tsx
<HanziKicker hanzi="大学">Каталог</HanziKicker>
<HanziKicker hanzi="我的计划" as="h2">Мой план</HanziKicker>
<HanziKicker hanzi="事实" tone="inverse">Факты</HanziKicker>   // на красной/тёмной полосе
```

| Проп | Значения | По умолчанию |
|------|----------|--------------|
| `hanzi` | иероглифы | – (обязателен) |
| `children` | русское значение | – (обязателен) |
| `as` | `div` · `h2` · `h3` · `span` · `p` | `div` |
| `tone` | `default` (иероглиф `accent-text`, подпись `fg-muted`) · `inverse` (иероглиф `gold`, подпись `paper/80`) | `default` |

Словарь разделов: 大学 Каталог · 我的计划 Мой план · 事实 Факты · 截止日期 Дедлайны · 考试 CSCA · 文件 Документы · 费用 Стоимость · 宿舍 Общежитие. Не больше одного кикера на блок, всегда с русским рядом.

## Компоненты `ui/*` (API не менялся)

| Компонент | Что изменилось |
|-----------|----------------|

| `Badge` | `rounded-md` (печатный ярлык, не пилюля); варианты те же: `default` красный на `accent-soft`, `secondary` серый, `positive`/`warning`/`destructive`/`outline` |

| `Input` / `Select` / `Textarea` | `rounded-lg`, `bg-card-2` |

## Тема

- Default – светлая, без атрибута. `App.tsx`: `usePersist("theme", "light")`, `<html data-theme={theme}>`; стили тёмной – только под `[data-theme="dark"]`.
- Ключ localStorage `admitica.theme` прежний; предзагрузочный скрипт в `index.html` ставит `data-theme="dark"` до первой отрисовки.
- `color-scheme: light` по умолчанию, `dark` под атрибутом – нативные селекты и скроллбары следуют теме.

---

## Движение (motion)

- **Easing:** `--ease-out-soft: cubic-bezier(0.16, 1, 0.3, 1)`
- **Длительности:** `--duration-fast: 200ms` · `--duration-base: 250ms` · `--duration-slow: 300ms`
- Анимировать только `transform` и `opacity`. Уважать `prefers-reduced-motion`.

---

## Производные и точечные цвета (не токены)

- **Тень белой карточки** (только светлая): `0 1px 2px rgba(29,29,27,0.04)` + `0 10px 28px -20px rgba(29,29,27,0.20)`.
- **Трек range-слайдеров**: `color-mix(in srgb, var(--color-fg) 10%, transparent)`; ползунок – `--color-accent` с кремовой обводкой.
- **`.hero-glow`** (Home, Onboarding, LeadInvite): слабая красная тонировка сверху, не свечение.

---

## Цвет программ (вне дизайн-системы)

У каждого вуза/гранта/стажировки есть собственный цвет аватара (`color`), который лежит **в данных** (`data/programs.js`). Это цвет кружка/плитки конкретной карточки, **не часть темы** – менять палитру тем его не затрагивает.
